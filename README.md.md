# MiluiMate - מערכת שיבוץ חכמה 🪖

מערכת מידע המבוססת על מנוע אופטימיזציה (CP-SAT) שנועדה לייעל את תהליך השיבוץ והיציאות של לוחמים במילואים, תוך שמירה על כשירות מבצעית והוגנות מקסימלית.

## טכנולוגיות מרכזיות:
* **Frontend/UI:** Streamlit (Python)
* **Backend/Algorithm:** OR-Tools (Constraint Programming - CP-SAT)
* **Data Processing:** Pandas, Numpy
* **Data Visualization:** Matplotlib

## איך להריץ את המערכת מקומית:
1. ודאו שמותקן אצלכם Python.
2. התקינו את הספריות הנדרשות בעזרת הפקודה: `pip install -r requirements.txt`
3. הריצו את האפליקציה בעזרת הפקודה: `streamlit run app.py` (או שם הקובץ הראשי שלכם).
